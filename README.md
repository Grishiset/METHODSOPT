## Воспроизведение

Проверено с Python 3.12.14, NumPy 2.3.5, SciPy 1.16.3, HiGHS 1.8.0 и Matplotlib 3.10.7. Из корня репозитория в активном окружении Python:

```console
python -m pip install -r requirements.txt
python lab1/solve.py
python lab2/solve.py
python lab3/solve.py
```

Каждая команда читает сохранённый файл варианта и обновляет результаты своей работы. Ключ `--generate` отдельно воспроизводит исходный JSON. Время в таблицах относится к конкретному запуску. Все исходные данные лабораторных синтетические. Стоимости, объёмы и расстояния измеряются в единицах, указанных в отчётах.
